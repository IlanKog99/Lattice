* Your grid file is now locked to your Windows account (Windows DPAPI). Nothing to do: it upgrades itself the first time this version starts, with no unlock prompt.
* New `/export`: saves a passphrase-protected copy of the grid you can take to another PC or Windows user.
* New `/import`: replaces the grid from an exported file (asks for its passphrase, then Yes/No). `/undo` brings the old grid back.
* A grid file copied from another Windows account now opens read-only with a hint, instead of being overwritten. Export it there and `/import` it here.
