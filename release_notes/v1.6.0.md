* Updates are no longer installed automatically. Lattice now only checks for a new version when it starts, and once a day while it stays open.
* When a new version is out, a popup shows what changed and a link to it on GitHub. Pick **Remind me later** to see it again once a day (with a short note in the top bar), or **Ignore** to skip it until the next launch.
* `/update` now downloads and installs the new version, then relaunches Lattice in the same window.
